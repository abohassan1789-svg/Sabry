# A-H CODE — دليل التثبيت

ملف التثبيت: **`A-H_CODE_Setup.exe`**

الملف ده فيه البرنامج كامل ومعاه كل المكتبات اللي محتاجها. مش محتاج تثبّت Python ولا أي حاجة تانية خاصة بالبرنامج.

---

## المطلوب قبل التثبيت

- **PostgreSQL متثبت** على الجهاز الرئيسي، والخدمة بتاعته شغالة.
- **كلمة سر المستخدم `postgres`**: هتكتبها أثناء التثبيت.

---

## 1) جهاز واحد بس

1. شغّل `A-H_CODE_Setup.exe`. هيطلب صلاحيات مدير، وافق.
2. سيب مكان التثبيت زي ما هو (`C:\Program Files\A-H CODE`) أو اختار غيره.
3. صفحة **Database Connection**:
   - `Server IP / Host` = `localhost`
   - `Port` = `5432`
   - `Database Name` = `SABCONTDB`
   - `User` = `postgres`
   - `Password` = كلمة سر postgres
   - اضغط **Test Connection**. لو القاعدة لسه مش موجودة هتظهر رسالة إنها «هتتعمل»، وده طبيعي.
4. صفحة **Network**: سيب الاختيار **فاضي**.
5. صفحة **Backup Folder**: سيب الافتراضي أو اختار فولدر تاني (فلاشة أو هارد خارجي مثلاً).
6. Install، وبعدها Finish.

ملف التثبيت هيعمل لوحده الحاجات دي:
- يحفظ بيانات الاتصال مشفّرة.
- ينشئ قاعدة `SABCONTDB` لو مش موجودة، ويبني الجداول والمستخدم الافتراضي والصلاحيات.
- لو القاعدة موجودة قبل كده، **مش هيمسح ولا يغيّر أي داتا فيها.**

---

## 2) شبكة: الجهاز الرئيسي

ده الجهاز اللي عليه PostgreSQL والقاعدة.

- نفس خطوات «جهاز واحد» بالظبط، بس في صفحة **Network** علّم على:
  **This is the MAIN machine - allow other computers on the network to connect**
- ملف التثبيت هيعمل لوحده:
  - يسمح لأجهزة نفس الشبكة تتصل بـ PostgreSQL. بياخد نسخة من ملفات الإعداد الأصلية الأول، باسم `*.ahcode-bak-…` جوه فولدر data بتاع PostgreSQL.
  - يعيد تشغيل خدمة PostgreSQL.
  - يفتح بورت `5432` في Windows Firewall.
- اعرف **IP الجهاز ده** عشان هتكتبه على باقي الأجهزة. تقدر تشوفه من الأمر `ipconfig`، في سطر IPv4 Address، زي `192.168.1.10`.

> يُفضّل يكون IP الجهاز الرئيسي ثابت. اطلب ده من مسؤول الشبكة أو اظبطه من إعدادات الراوتر.

---

## 3) شبكة: باقي الأجهزة

1. شغّل نفس الملف `A-H_CODE_Setup.exe`.
2. في صفحة **Database Connection** اكتب **IP الجهاز الرئيسي** مكان `localhost`، وباقي البيانات زي ما هي.
3. اضغط **Test Connection**، ولازم يظهر «Connected».
4. صفحة Network مش هتظهر على الأجهزة دي.
5. كمّل التثبيت.

كل الأجهزة كده هتشتغل على نفس الداتا.

---

## أول تسجيل دخول

- اسم المستخدم: **`Admin`**
- كلمة السر: هتستلمها من المسؤول عن البرنامج.
- غيّر كلمة السر بعد أول دخول.

## التحديث

- شغّل النسخة الأحدث من `A-H_CODE_Setup.exe` على نفس الجهاز.
- البيانات هتظهر مكتوبة جاهزة، اكتب كلمة سر postgres بس.
- الداتا والإعدادات والنسخ الاحتياطي محفوظة زي ما هي.

## إلغاء التثبيت

من «إضافة أو إزالة البرامج» شيل **A-H CODE**. ده بيشيل البرنامج والاختصارات بس، و**قاعدة البيانات وبيانات الاتصال والنسخ الاحتياطي بتفضل زي ما هي.**

## حل المشاكل

| الرسالة أو المشكلة | الحل |
| --- | --- |
| `password authentication failed` | كلمة سر postgres غلط، اكتبها تاني. |
| `Connection refused` أو `timeout` على `localhost` | خدمة PostgreSQL واقفة. شغّلها من Services، اسمها بيبدأ بـ `postgresql-x64-`. |
| `timeout` على جهاز شبكة | 1) اتأكد من IP الجهاز الرئيسي. 2) اتأكد إنك علّمت اختيار Network وانت بتثبّت على الجهاز الرئيسي. 3) اتأكد إن الجهازين على نفس الشبكة. |
| `database "SABCONTDB" does not exist` على جهاز شبكة | ثبّت على الجهاز الرئيسي الأول، أو اتأكد إنك كاتب IP الجهاز الرئيسي صح. |
| التثبيت وقف عند خطوة معيّنة | افتح سجل التثبيت في `C:\ProgramData\PHASEINV2\logs`، واضغط Retry بعد ما تحل المشكلة. |
