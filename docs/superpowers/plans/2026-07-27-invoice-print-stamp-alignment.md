# Invoice Print Stamp Alignment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Print the optional company stamp at the physical right directly below the totals in all eight Saudi sales-invoice templates, using a vivid 140px-by-100px presentation.

**Architecture:** Keep stamp HTML and visibility rules centralized in `saudi_invoice_print.py`, because all eight builders already call `stamp_overlay_html(data)`. Add one shared layout-reserve function, then have the six fixed-height/paginated templates subtract that reserve from their last-page row budget only when a printable stamp exists; the two naturally flowing templates need no pagination change.

**Tech Stack:** Python 3.11, HTML/CSS generated by Python f-strings, pytest, existing invoice pagination helpers.

## Global Constraints

- Apply the visual change to `saudi_invoice_print.py` and templates `v2` through `v8`.
- Keep the stamp directly after the totals in normal document flow.
- Align to the physical right regardless of the surrounding RTL/LTR direction.
- Use a 140px by 100px image box with `object-fit: contain`.
- Use `opacity: 1` and `filter: saturate(1.25) contrast(1.12) brightness(1.03)`.
- Keep a 10px gap above the stamp.
- Preserve the existing checkbox and missing-stamp behavior.
- Do not change logos, QR codes, totals, invoice data, or stamp bytes stored in the database.
- Use `C:\Users\esraa\AppData\Local\Programs\Python\Python311\python.exe` for tests and compile checks.

## File Structure

- Modify `app/ui/screens/saudi_invoice_print_v3.py` through `saudi_invoice_print_v8.py`: consume the shared reserve in fixed-height pagination.

- [ ] **Step 3: Implement the shared dimensions, style, and reserve**

Replace the old size constant and helper body in `saudi_invoice_print.py` with the following contract:

```python
_STAMP_PRINT_WIDTH_PX = 140
_STAMP_PRINT_HEIGHT_PX = 100
_STAMP_MARGIN_TOP_PX = 10
_STAMP_FILTER = "saturate(1.25) contrast(1.12) brightness(1.03)"


def stamp_layout_reserve_px(data: dict[str, Any] | None) -> int:
    """Vertical pixels reserved on a fixed-height last page for a visible stamp."""
    if not isinstance(data, dict) or not data.get("show_stamp"):
        return 0
    if not company_stamp_data_uri(data.get("seller")):
        return 0
    return _STAMP_MARGIN_TOP_PX + _STAMP_PRINT_HEIGHT_PX


def stamp_overlay_html(data: dict[str, Any] | None) -> str:
    """Return the optional right-aligned company stamp below invoice totals."""
    if not isinstance(data, dict) or not data.get("show_stamp"):
        return ""
    uri = company_stamp_data_uri(data.get("seller"))
    if not uri:
        return ""
    return (
        f'<div data-company-stamp="1" style="margin-top: {_STAMP_MARGIN_TOP_PX}px; '
        'text-align: right; page-break-inside: avoid; break-inside: avoid;">'
        f'<img src="{uri}" alt="stamp" style="width: {_STAMP_PRINT_WIDTH_PX}px; '
        f"max-width: {_STAMP_PRINT_WIDTH_PX}px; height: {_STAMP_PRINT_HEIGHT_PX}px; "
        f"max-height: {_STAMP_PRINT_HEIGHT_PX}px; display: inline-block; "
        f'object-fit: contain; opacity: 1; filter: {_STAMP_FILTER};"></div>'
    )
```

def test_fixed_template_reserves_visible_stamp_on_last_page(monkeypatch, module, build):
    observed: list[float] = []
    real_paginate = module.paginate

    def capture(lines, row_height, *, budget, budget_last, foot=0):
        observed.append(budget_last)
        return real_paginate(
            lines,
            row_height,
            budget=budget,
            budget_last=budget_last,
            foot=foot,
        )

    build(_sample_data())
    build(_stamped_data(show=True))

    assert len(observed) == 2
    assert observed[0] - observed[1] == 110
